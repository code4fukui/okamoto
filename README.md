# Kidssafe Okamoto
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

Kidssafe Okamoto is a civic tech project that aggregates regional information for the Okamoto district of Echizen City, Japan. It can be used as a kid-friendly local map.

## Demo
[Kidssafe Okamoto](https://code4fukui.github.io/kidssafe-okamoto/)

## Features
- Displays major facilities in the Okamoto district on an interactive map
- Shows facility names and URLs

## Data / API
Regional information is managed in the [point.csv](point.csv) file. Open data utilization is also under consideration.
