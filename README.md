## About This Repository

This repository originally hosted an interactive civic tech map for the Okamoto area of Echizen City. Its primary function is now to redirect users to the current, active version of the project.

The archived project files remain, including:

- **`index.html`**: A simple page with a JavaScript script that redirects to the new map.
- **`point.csv`**: The original location data file, containing points of interest with `名称` (name), `Geo3x3` (grid code), and `URL` fields.
- **`images/`**: Original UI assets, including menu/close icons (`icon_menu.svg`, `icon_close.svg`), an emergency alert icon (`aioi_3.png`), and a drone icon (`drone_icon.png`).
- **`.nojekyll`**: Disables Jekyll processing for deployment on GitHub Pages.
- **`.gitignore`**: Configured to ignore Jupyter Notebook checkpoint files (`.ipynb_checkpoints`).
