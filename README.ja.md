# Kidssafe Okamoto
Japanese README: [README.ja.md](README.ja.md)

Kidssafe Okamoto は、日本の越前市の岡本地区の地域情報を集約するシビックテック・プロジェクトです。子供にもやさしい地域マップとして使えます。

## デモ
[Kidssafe Okamoto](https://code4fukui.github.io/kidssafe-okamoto/)

## 機能
- 岡本地区の主要施設を対話型のマップに表示します
- 施設名とURLを表示します

## データ / API
地域情報は[point.csv](point.csv)ファイルで管理されています。オープンデータの活用も検討中です。
